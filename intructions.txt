# College ERP — Antigravity Master Instructions

## Project Overview

Build a production-grade enterprise-level College ERP platform for a B.Tech college using:

* React + JSX + Vite
* Tailwind CSS
* Node.js + Express
* MongoDB
* Resend Email Integration

This ERP must look and behave like a real enterprise SaaS platform used by universities and institutions.

The UI must feel modern, clean, structured, scalable, and premium.

Avoid generic AI-generated UI patterns.

---

The design language must be inspired by:

* Linear
* Stripe Dashboard

* Modern enterprise SaaS products

The UI should feel:

* Cartoonish UI
* Random gradients
* Excessive glow effects
* Neon colors

* Generic AI layouts
